# ADR-024：公开报告阅读计数

2026-11-03，用户要求公开报告列表与详情显示阅读量、收藏量，并调整悬浮胶囊导航与精简首页介绍。

## 阅读口径

列表、详情和下载 GET 不增加计数。公开报告详情成功载入且页面可见后，浏览器通过同源 BFF 发起一次 POST，记录有效浏览。同一浏览器/同一报告/北京时间自然日最多一次，刷新及重复请求幂等；不同浏览器或跨日再次阅读可累加。初始历史计数为0，不伪造历史热度。该口径不是独立自然人数，也不是付费/安全指标；清除 Cookie、跨设备或主动伪造请求可能产生额外计数，不宣称防刷系统。

BFF 发放30天 HttpOnly / SameSite=Lax 随机UUID Cookie，详情 GET 预先初始化，POST 校验同源并只使用服务端读取的Cookie，不转发请求提供的访客身份。详情组件避免重复挂载效应发出重复POST；后端仍独立去重。API维持原有本地部署边界。

数据库只保存按报告/日期加盐的SHA-256哈希，不保存Cookie原值、IP、邮箱或账号关联。后续阅读请求清理早于昨日的去重明细；没有新请求时不会声称已按时清理。聚合总数单独保存，不因明细清理归零。聚合为公开报告统计，不建立用户阅读历史。

## 存储与并发

0019_reads 新建 community_report_metrics 与 community_report_reads。明细主键为报告/日期/哈希；报告行锁将去重与聚合递增串行放入同一事务，避免并发重复和丢失更新。阅读前后验证公开可见性；撤回后他人不能继续记录阅读。删除公开记录时通过外键CASCADE清除两张表数据。

收藏数继续查询真实 community_bookmarks，不新增副本计数。列表批量查询阅读聚合，详情读取单条聚合；契约新增views_count并重新生成。统计失败不阻止用户阅读，展示最后取得的真实聚合。现有点赞、收藏、个人数据权限、研究/邮件能力不扩张。

## 界面

用户顶部导航为悬浮胶囊，当前页面使用填充式胶囊选中态；移动端展开为独立圆角导航。继续用导航链接语义，不把页面跳转伪装为ARIA tab面板。后台管理界面不受影响。

首页保留Agent标识、主标题和一句简介；演示研究/实时监听与邮件提醒待启用的提示移动到研究入口卡片，避免将尚未接入的能力描述成已运行。浅深色、键盘焦点与减少动画偏好继续支持。
