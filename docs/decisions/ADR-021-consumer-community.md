# ADR-021：C 端行业发现、显式分享与对话研究入口

用户选择最新设计方案第 2 张，授权重构全部用户前台、增加行业/报告分享与收藏、聊天研究入口；后台管理延后。预测规则待用户补充，本轮不新增或改变预测算法，不开启真实定制研究、真实支付、公开部署或额外真实邮件。

沿用 Next.js → 同源服务端 BFF → FastAPI → PostgreSQL / 原有 Job Worker。公开读取只开放 community 下的行业、公开报告 DTO；会话令牌仍只存在 HttpOnly cookie / BFF，API 校验独立注册账号与每一个对象的归属。所有变更保留同源限制，私有与公开快照接口都不缓存。

行业与报告分别显式公开，默认私密。添加行业只创建本人收藏关系；不得复制另一用户私有报告、画像或研究对话。报告分享先预览，从已过审且原本可公开的世界版本中提取观察、前提和证伪条件，固定到明确的报告版本。个人影响、私人建议、画像、聊天、邮箱和内部 owner ID 不进入公开 DTO；含私有研究来源的报告拒绝公开。行业撤回后停止公开发现，已有成员可保留入口；报告撤回后公开详情和他人的收藏读取都返回不可用。撤回只能阻止后续读取，无法收回第三方已保存的公开副本。

收藏归属行业与公开报告原行业独立；私有报告归档是本人关系。作者删除个人资料时清除发布快照、私有归档、对话与收藏，其他人的指向该发布快照的收藏通过外键级联清除。已分享行业保留无身份的撤回占位，清除原名称和简介；不破坏其他用户的私人研究关系。新对象加入导出/删除和备份删除登记重放。

对话正文和标题按 user/entity AAD 使用原 AES-GCM 密钥加密，消息有长度/总量上限、客户端请求 ID 去重与同键异文冲突。对话状态绑定实际 Job，刷新后从数据库恢复。当前对话回复为确定性的范围提示，不声称是模型回答；生成入口明确确认复用演示资料，走现有首份报告权益与 Worker。未执行的联网检索、推演、审查标记为未执行/沿用，不显示虚假的进行中、完成时间、百分比或模型思维链。自由问题的新预测和真实深度搜索留待用户规则明确后接入。

首次展示提供独立、明确标注的阅读示例，不伪装真实用户研究或真实预测成绩。公开推荐只使用本人行业画像代码与已添加行业，不把个人选填信息发给模型。

视效采用选定绿白方案，原生 CSS 短时淡入/位移/悬停、图片过渡与真实加载状态；prefers-reduced-motion 关闭动画。导航分离用户前台与原管理入口，管理业务与权限不改。
