# ADR-017：本人数据删除、不可变审计与恢复后的删除重放

用户授权 M7；继续本机原生部署，不开放公网或真实收款/邮件。

删除 API 仅作用于当前注册账号，要求当前密码与明确的 DELETE MY DATA 确认；复用登录 KDF/尝试限制。
按用户→Job锁序取消待完成任务、释放预留、停用周期/订阅续订。清除登录标识/会话、画像、所有私人报告版本、影响/建议/反馈、邮件内容/退订能力、本人研究quote及原主题引用。
仍被必要研究/计费请求外键引用的画像快照只允许改为 ERASED 和零hash，不保留原密文。
任务输入/结果/任意幂等键被清理；套餐订单只允许清理任意客户端请求键/hash，价格/额度/事件/流水仍不可改。
UserTopic 断开原人群/行业研究关联。保留随机用户ID及必要份额/订单审计，公开共享研究不随个人账号删除。

Migration 0011_m7 通过永久追加写的 privacy_erasures 授权窄范围 owner 删除与精确 tombstone，
没有 session bypass、禁用触发器或改写世界版本的例外；普通删除/更新仍拒绝。
恢复/删除审计存在后不允许降级删除该登记。再次删除/跨用户/密码错误不能触及其他人的资料。

本机加密备份包含旧数据库页，普通 DELETE 不承诺物理介质/WAL取证擦除。
因此额外保存0600、HMAC签名、fsync的外部 erasure-journal；账号删除确认前登记，备份恢复切流前重放。
外部日志只含随机用户ID、删除ID与时间，不包含邮箱或画像。不能只恢复旧DB而遗漏最新删除日志。
历史备份保留期限和物理介质策略仍需正式运营确定；用户页面明确说明此边界。

备份使用独立32字节 transport key 加密认证，不能与业务 profile key 是同一文件。
恢复演练只创建唯一的 *_restore_drill 数据库，比较同一MVCC快照的表计数/报告与世界版本摘要，
解密检验私有报告，再重放备份之后的删除登记，最后删除演练库。绝不原地覆盖用户数据库。
删除登记和备份解密key必须独立于数据库备份保存；恢复后还需对账备份之后的额度/支付变化。
