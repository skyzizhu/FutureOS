# ADR-013：M4 首份报告、版本复用与本地邮件授权

状态：已采用。只实施 M4，不实施周期调度、支付或真实邮件。

报告生成沿用持久化 jobs/租约/outbox/inbox。先冻结最小画像，再预留1个首次完整报告权益，长任务返回202。
同用户行锁、同用户幂等键、reserved/consumed 部分唯一索引和 ledger 唯一约束共同阻止并发重复消费。
一份报告组合多条世界预测只消费一次；成功时私有报告、关联、额度消耗、结果和完成事件在同一租约事务提交。
失败/取消/租约耗尽释放；消费后的权益不能回退为 released。页面刷新可找回自己的待完成任务。

首次执行固定要引用的 ForecastVersion ID 和 Core hash；输入时间固定，重试不重新选择最新版本。
主引擎不会将个人目标/任务传给 DeepSeek；M4 不自动调用外部模型或检索。
REAL 仅复用已发布过审的世界版本，没有资料则失败并释放额度。DEMO 用当前时间的自编合成材料，
仍经完整 M2/M3 审查与发布闸门；native 单机文件锁串行化 Mock 目录初始化，多个用户复用同一固定版本。
该锁不是分布式调度方案；多主机部署需替换。过期合成目录不偷偷更新成新世界结论。

Core 先用行业领域、目标范围/地区、条件机制和任务词汇作可解释匹配，不因自由文本非空就评为高关联。
没有直接路径的条目仅在观察附录，不进核心建议。用户未授权选填、缺任务/目标/时间预算、DEMO、
高成本/不可逆/高风险领域时不能升为 prepare；真实可选验证也只允许无新增付费、可停止且不接触生产敏感数据的动作。
建议包含适用条件、成本、取舍、替代、验证指标和停止条件，不保证个人收益。
这是模板/规则原型，不是已验证的个性化因果模型或行业覆盖承诺。

ReportVersion/快照/个人影响/建议/固定世界版本引用追加写，后续画像编辑不覆盖旧报告。
报告和世界预测版本分别有时间线；建议反馈另行追加，不改原报告。

邮件只提供固定摘要和鉴权私有链接预览。用户必须明确授权、确认账号邮箱，才保存一次本地模拟记录；
收件人加密，按用户/报告版本去重，不调用 SMTP 或真实 EmailProvider，不发送真实邮件。
授权和预览不消耗新的研究额度。真实邮件、退订/退信和周期策略属于后续 M5。
