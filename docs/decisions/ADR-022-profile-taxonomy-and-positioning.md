# ADR-022：预测 Agent 定位与画像表单 v2

2026-11-02。用户要求：首页明确未来行业/机遇预测Agent与实时监听目标；扩展行业层级；国家选择、省/州手填；增加选填年龄/性别；解释并简化目标/任务/时间字段。

## 定位与真实能力

首页明确“未来行业与机遇预测Agent”，说明“AI实时监听行业动态、形成趋势与机遇预测报告”为产品目标。当前scheduler复核已接入的本地资料，并非已完成全行业实时联网采集，因此同屏说明当前为公开报告/演示研究体验、实时联网监听与新预测规则待接入。不因文案需求自动开启真实付费调用或定时联网研究。

## 行业目录

产品自定义两级目录 v2：23个一级方向、259个二级方向。参考[国家统计局分类层次及行业门类](https://www.stats.gov.cn/zs/tjws/tjbz/202301/t20230101_1903769.html)，结合产品原有代码和AI等新兴细分展开，不声称是官方分类代码或官方全部小类。保留全部v1 code/parent组合；新增主要行业及每个正式行业下的手填兜底。选择 *_other 需填写细分说明，属于行业范围，非选填个人资料；最小研究快照仍保留这一说明。

0016迁移仅追加冻结的目录数据，不改写已有分类、画像或报告快照。年龄、性别、国家与省/州通过既有加密画像JSON保存，无需新增明文个人数据列。仅在没有现存画像时允许回退，且保留无引用的追加目录，遵守append-only约束。

## 地区与人口信息

国家/地区选项来自[Unicode CLDR](https://cldr.unicode.org/translation/displaynames/countryregion-territory-names)，固定数据提交 d2f155b4b2fd98b0b2453e2e09ce76794b5749c2，258个可选地区代码。名称包含国家和地区，不将其声称为258个主权国家。省/州为自由文本；美国显示州，中国显示省/自治区/直辖市，其他地区显示省/州/地区；切换国家清空旧省/州。许可归档于docs/vendor/unicode-cldr-LICENSE.txt。

旧region文本继续可读，UI不猜测拆分；新表单保留原文本或按所选国家保存兼容region。既有地区匹配规则优先读取country_code，无country_code时仍使用旧region，不新增省/州预测规则。

年龄与性别默认空、完全选填。年龄接受1–120整数；性别可为空/女/男/其他。两者在当前画像中加密保存、本人可修改/导出/删除，但即使授权使用选填资料，也清空研究快照中的值，不用于预测或推荐排序。不按人口信息改写客观世界预测。

## 关注偏好

目标改为“你更关心什么”，使用勾选与补充单项，最多5项；不要求用户输入分号。原任务改为“希望重点关注的工作/业务”，逐项添加、最多8项；解释为判断变化与日常工作的关联。时间改为愿意投入小尝试的时长，放在可跳过的进阶区，明确不影响报告生成速度。保留既有goals/tasks/available_minutes_per_week协议及旧值，避免改变原有研究/行动规则。

岗位、地区、关注偏好仍需原有显式授权才进入研究快照；未授权仅使用行业。修改画像不覆盖已有报告。

## 回归发现

目录扩展加长了请求窗口，SQLite并发用例暴露原有同键首报竞态：首次查不到Job后，另一请求提交并占用权益，当前请求误报额度不足。额度不足前重新核对同键的已提交Job；同内容返回同一作业，异内容仍冲突，不改变权益数量或预测规则。

## v2.1：用户指定的互联网职业细分（2026-11-02）

当前产品目录将 technology 的显示名改为“互联网与信息技术”，增加 technology_product_management（产品经理）与 technology_ui_design（UI设计师），合计23个一级方向、261个二级方向。保留 technology/software 等已有 code、父子关系和领域标签，不改写旧画像或报告快照。两项新细分使用现有 technology/workforce 领域映射，不扩展研究或提醒规则。

“暂不适用职业行业”是学生、退休及不希望按职业分类用户的身份兜底，并非实际行业。产品显示名改为“暂不按职业分类（学生／退休等）”，选中时补充说明，保留原有 not_applicable/student/retired/other 代码。

公开目录接口继续提供当前产品目录 v2.1，历史数据库目录记录保持 append-only，其旧名称不回写；0018_tech_roles 仅追加两个新细分，确保已有数据库中的画像外键可用。既有不可变保护和历史版本不受名称调整影响。
