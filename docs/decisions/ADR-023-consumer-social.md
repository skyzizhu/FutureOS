# ADR-023：公开内容、个人多行业与报告互动

2026-11-02。用户要求公开行业/报告的产品语义、行业可添加为自己的行业、多行业管理、报告下载/点赞/收藏和作者消息、主题与封装控件，所有业务状态必须落库。

## 数据与边界

保留 `community_*` 内部接口以兼容已有客户端，用户文案统一使用“公开”。新增迁移 `0017_social`，建立个人行业来源映射、按行业的关注设置、账号外观、点赞及作者互动消息五张表。契约源仍为 Pydantic，生成 TypeScript/OpenAPI；业务持久化留在 infra 与 API，不进入预测 core。

添加公开行业会创建当前用户拥有、默认私有的独立副本，记录源行业 ID。同一用户/来源唯一，重复添加返回原副本；用户可独立修改、公开或整理报告，不复制原作者的私人报告。一个用户可管理多个行业。原有关注接口兼容保留，新的用户界面使用添加副本接口。移除个人行业的关注时同步暂停其关注设置，不删除已有报告。

每个自有行业分别保存监听、预测、邮件意愿。新建/复制行业同时落库，迁移为已有自有行业补齐设置。默认监听和预测意愿开启、邮件意愿关闭。状态为 `waiting_rules` 或 `paused`，**没有接入新的抓取、预测调度或邮件派发**。用户稍后给出规则，再把已保存意愿接到执行层；不能将意愿显示为正在实时执行。

报告沿用公开内容的固定快照与撤回权限。查看继续允许访客阅读；登录用户可下载 UTF-8 Markdown，内容仅限公开快照，含演示/真实资料与不确定性说明，不含画像和私人行动建议。撤回报告或所属行业后，他人不能继续获取下载内容。

## 互动与隐私

点赞和收藏按用户/报告持久化，返回数据库真实计数与本人状态。操作前对用户加事务锁，重复请求幂等。首次点赞/收藏在同一事务产生作者站内消息；同一读者/报告/动作唯一，取消后再操作不重复打扰。不给示例内容或本人互动发送消息。消息只向作者本人提供，隐藏读者标识，支持独立标记已读；导航提示未读互动，进入页面时刷新，无后台轮询。

新增个人数据纳入导出及删除：偏好、来源映射、关注设置、点赞、收件箱；删除账号同时清理其发送/接收的互动。已被其他用户复制的公开行业介绍归副本持有者管理，不会连带删除他人的独立行业副本。公开快照原有最小化与撤回策略不变。

## 控件与主题

用户侧统一使用轻量 React 输入/按钮/复选框/开关封装，以及基于 Radix Select 的下拉控件。保留可访问名称、键盘和焦点、禁用与错误语义，弹层有滚动及边界避让。后台管理界面暂不重构。

默认跟随操作系统，支持浅色/深色。主题在首屏脚本中提前应用，避免等待账号请求后才首次上色；游客保存在当前设备，登录用户选择同时保存到账号数据库，下次登录读取。系统模式监听系统外观变化；所有模式使用 CSS 变量和短过渡，支持减少动画偏好，不引入视频/大型动画依赖。

## 产品目标与后续

首页明确未来行业与机遇预测 Agent，目标为采集动态、行情、政策，判断未来影响，给出生活、工作、学习建议及邮件提醒。现有演示研究与已接入资料的处理保持原有边界。实时抓取策略、预测规则、触发/频率、邮件去重和投递策略待用户补充，不因本次设置自动执行外部调用。
