# ADR-016：标准化沙盒主题、共享复用与成本观测

M6 选择式引导限定行业、关注点、人群、地区与DEMO/REAL标签，使用带规则版本的 canonical fingerprint。
不把自由文本微调当新主题收费；同用户已完成的同一规范主题返回原报告/免费复查。
提交前冻结15分钟有效的 quote 与用量规则；显式接受后才预留，范围引导本身不扣额度。
当前新研究执行仅支持 DEMO，REAL 定制任务明确失败并归还，不自动使用 DeepSeek 或编造真实版本。
这是合成流程模板，不是已验证的自由问题意图识别/主题新颖性判定或全行业研究能力。

世界层只读取标准范围与 M1 合成证据，不读取个人画像/任务/目标。
同一共享范围行锁串行初始化，只做一次 Mock M2 研究及独立 M3 Critic，过审才能生成世界版本。
研究输入、模型叙述、代码工件、来源/主张/指标引用与草稿均冻结，保留原研究的离线重放。
不同用户各自以经授权的最小画像快照生成加密私有报告；共享研究复用不泄露用户身份与画像。

已有世界版本时复查本地输入：T0/T1 保留世界版本；T2/T3 复用 M5 分级/预算/冷却和独立审查。
新建的内部复查在父任务最终事务内处理；已有进行中或失败的共享复查不被越过租约强行抢占，父任务失败归还额度。
更新原主题的已存在报告仍经 M5 免费更新；额外的新主题完整私有报告与已授权周期服务按提交前规则使用1份套餐额度。
周期服务即使复用未变化世界版本也会重新核对输入并生成固定画像/报告；该服务用量规则须在开启前明确说明。

成本记录是追加写观测：共享解析/复用、独立 Critic、个性化、增量复核与执行尝试分别记录耗时和逻辑模型调用。
复用的旧模型响应不再次算新模型调用；有供应商 usage 则保存计量，未配置真实单价时金额为未知，不能补造历史成本。
零外部调用的本地阶段外部费用记录为0，但不包含本机计算、维护与人员成本，也不代表生产单次研究成本。
观测从M6开始。真实价格表校准、压测、经营条款、生产Provider灰度与质量验收留在M7上线准备。
