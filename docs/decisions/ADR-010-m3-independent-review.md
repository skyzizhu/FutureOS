# ADR-010：M3 独立审查、定向复核和发布

状态：已采用。2026-11-01 用户明确授权进入 M3，免去 M2 人工验收等待；不实施 M4。

五类 Critic（Evidence、Historical、Causal、Scenario、Temporal/Resolution）是确定性审查器，
不与主引擎混合投票，也不生成替代预测。独立查证重新查询 M1 中同标签、同领域、原 cutoff 可获取的资料；
范围仍有上限，不声称穷尽网络证据。只传草稿和冻结证据 DTO，不传主推演提示词。

审查在独立 Python -I/-B 子进程执行；环境白名单不含模型/数据库/代理凭据。
可信模块导入完成后，审计钩子拒绝网络、子进程以及文件访问/写入，15秒超时。
Critic 没有 ORM Session、SQL 工具或发布接口。该隔离限制受控审查代码的能力；不是任意敌对 Python 的 OS 沙箱。
Core 依旧不能导入 infra/apps/workers/HTTP/数据库。主进程负责查询与追加保存结果。

结构性事实（引用片段、来源簇、时间、指标口径/基线、案例结果、目标字段）直接比较证据后标记 verified。
这不等于自动证明自然语言 claim 的语义真实性或因果关系；M1 人工/编码代理核对仍须注明来源和限制。
合理竞争解释为 L1，仅附注；verified L2 触发定向复核；verified L3 阻断。
pending L2/L3 不能放行；五类检查必须全部完成；B2 仍有实质问题则 research_only。

CriticRun、裁决记录、草稿 A/B1/B2、复核输入与差分均追加写。B 由主引擎生成而非 Critic 修改，
复用原叙述并纳入核实后的反证/指标/案例，不自动再付费生成。可补充已存档案例 ID，但不能改变冻结目标、期限或阈值。
缺少可核实资料时保持阻断，不用同义改写伪装修复；最多两轮，不允许 B3。
同父草稿只有一个子草稿，重复请求复用既有结果，冲突409。

0005_m3 解除 M2 的无条件发布禁令，换成匹配草稿 hash、审查、裁决和目标的数据库闸门；
0006_m3_gate_shape 绑定显式 cutoff/连续版本号/初始版本指针。发布只允许最新审查，
资料或 Core 变化必须重新检查；WorldForecast 的指针只能指向属于自己的最新已冻结版本。
ForecastVersion 及审查记录 UPDATE/DELETE 被阻断；DB 应用角色仍非超级用户。

发布记录保存原因、版本 hash、原始草稿及对应审查。DEMO 只在管理端用于合成演示，不能登记为真实前瞻；
REAL 必须目标和复查时间晚于当前时刻。没有公开发布页面、用户画像、邮件或计费。
