2026-11-02；当前仅限本机。负责人尚未指定，不代表上线批准。

## 启动、暂停与诊断

运行 `make build && make up`，Web http://127.0.0.1:3100；`make down` 关闭项目创建的服务。
管理页 `/admin/readiness`、`/admin/costs`、`/admin/monitor` 分别查看质量/积压、计量、复查。
停止 worker/scheduler 可暂停后续研究；不要删除 queued/running 记录或手工改额度。
若供应商结果不明，保留 uncertain 状态，核对供应商账单后人工处理，不能直接重试付费调用。
日志在 `.local/{api,worker,scheduler,web}.log`，支持材料仅包含时间、job/request ID、错误码，禁止复制邮箱、私有正文、Key、完整导出或 Cookie。
当前支持入口为项目维护者；正式运营前需要配置联系地址、响应时段和事故负责人。

## 备份与恢复

1. 本地服务启动后运行 `make backup-drill`。该命令创建并删除自己的合成账号，生成加密备份，恢复到唯一演练库，核对摘要、解密私有报告并重放删除记录，最后移除演练库。
2. 备份位于 `.local/backups/*.fosbackup`。加密包包含 PostgreSQL dump、业务私有数据密钥和清单；独立 `.local/backup-transport.key` 不能与备份包同地失控，均应0600。
3. `.local/erasure-journal.jsonl` 是删除后的外部签名登记，必须保留最新版本并独立备份；恢复旧数据库后，在对用户开放前重放。不能只恢复 dump。
4. `.local/engine_versions` 保存冻结 Core 工件，必须另外随备份归档；当前数据库加密包并不包含它。保存对应源码、uv.lock、package-lock.json、运行时与配置模板；私密 .env 单独托管。
5. 演练函数只允许项目管理的本地数据库，自动清理唯一演练库；不提供一键覆盖运行库。真实故障先停止写入，保留原库/日志，使用隔离库恢复；核对删除、额度、备份之后的交易/任务，人工确认后再切换连接。
6. 删除不是物理页/WAL擦除；备份保留期限、离线副本、定期演练、密钥轮换、RPO/RTO 和介质销毁策略尚未确定，不能宣称已达生产标准。

## 变更与回滚

升级前备份、冻结配置并记录当前迁移头。优先回滚兼容的应用代码，不随意降级数据库。
0011_m7 已有删除审计后拒绝 downgrade；旧版本可能无法理解 ERASED 快照，不能直接回滚到旧读取逻辑。
出现删除/扣费/越权疑似缺陷时，先停止相关任务和服务、保留审计，使用前向迁移修复；禁止绕开不可变触发器。
恢复后重新执行 `make check`、`make build`、`make local-verify`，核对正式协议/版本摘要及真实研究重放，不重复真实模型调用。
