# 首页行业 Banner 与导航操作区

- 副标题统一为「预见未来趋势，做更好的决定。」。
- 搜索与主题组成轻量工具组，登录和注册保留清晰的视觉层级。通知、账号、主题与菜单按钮的尺寸、边框和交互反馈一致，窄屏保留触控空间。
- 首页从现有公开行业目录生成横向 Banner。支持原生触摸及触控板滑动、桌面鼠标拖动、前后按钮和键盘方向键，滑动结束后吸附到单张行业卡片。切换行业时更新提问范围和报告列表。
- 复用本地行业配图。其他行业使用主题背景。侧边预留下一张卡片的边缘，轮播由用户操作。
- 已在本机 Chromium 验证鼠标拖动、键盘切换与模拟触摸滑动。视觉检查覆盖 1440px 桌面、390px 深色手机、360px 和 320px 窄屏。调整了工具组高度和深色箭头对比度。

## 验收

- `make check` 通过，包含 465 项 pytest。最后的文案及对比度调整复跑了 `npm run lint`。
- `make build` 通过，预渲染 16 个静态页面。
- `make local-verify` 通过，原生 PostgreSQL 与 Redis 验收包含 465 项 pytest 和 22 条浏览器流程。首页流程覆盖前后按钮、键盘、鼠标拖动以及行业报告联动。
- `make up` 已恢复本地服务，首页返回 HTTP 200。
