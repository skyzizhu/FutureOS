# C 端前台重构与社区内容增量

日期：2026-11-02。用户选择最新三张方案中的第 2 张（行业漫游，绿白、自然摄影、公开行业与报告），随后授权完成前台并增加轻量过渡。研究预测规则待用户另行补充；后台管理不在重构范围。

## 已实施范围

- 用户导航收拢为发现、行业、聊聊未来、我的；账号菜单承接偏好、安全、通知和套餐，管理入口从用户导航分离。
- 未登录可浏览公开行业、搜索/排序/分页阅读公开报告、打开报告详情；收藏和研究需要登录，登录/注册与画像完成后返回原入口，保留提问内容。
- 登录后首页默认根据画像行业与关注行业排序公开报告，展示推荐原因；可切换具体行业、最新/较早分享。
- 个人中心管理关注和自己创建的行业，支持编辑、独立公开/撤回、取消关注及重新关注。自己的行业即使取消关注仍保留管理入口。
- 我的报告、收藏、分享、研究对话分别管理。私有报告可归档到行业，收藏到自选行业，与原报告所属行业独立；已撤回报告不会继续通过他人收藏读取。
- 分享报告先生成公开预览，再单独确认。仅包含可公开世界版本的观察/前提/证伪条件，不复制私人影响、建议、画像或对话。公开结果固定于所选报告版本，可撤回，私人原件保留。
- 对话、补充问题和标题在服务端加密保存，按本人归属校验与客户端消息 ID 去重；刷新恢复。绑定实际 Worker Job，完成后链接到独立报告，不把完整报告塞进聊天气泡。
- 原有注册/密码显示/按需安全验证、画像、私有报告、建议、通知、安全设置、账单、引导研究使用统一前台样式；保留真实范围和模拟流程说明。
- 页面进入、分类切换、图片、按钮、消息和加载状态使用短时动画；减少动态效果时关闭动画。手机导航和窄屏布局单独适配。
- 生成图片经 WebP 压缩，5张在 public/images 下合计约324KB；原始生成文件保留在生成工具输出及本机 .local/ui-redesign/source-images。

## 明确的能力边界

聊天入口已接现有“复用已有资料的首份演示报告”流程，沿用既有画像、权益、审查版本和报告生成逻辑。当前聊天回复是确定性的范围提示，不是自由问答模型；自由提问与追问会保存，但不会冒充已完成的深度联网研究。界面明确标出本次未执行检索、新预测或新审查；不显示虚假进度或思维链。新预测规则与真实聊天 Agent 编排待用户补充规则后实现。

初始公开内容为明确标注的阅读示例，不伪装真实用户、真实预测成果或真实成绩。尚无社区真实内容时，用户仍可完整体验发现与收藏。现有生产上线限制、真实支付及报告邮件开关不变；本轮不公开部署、不额外调用真实模型或发送真实邮件。

数据边界和迁移见 ADR-021。新记录已纳入本人导出/删除；删除公开报告快照同时清理指向该快照的收藏。行业撤回与报告撤回分开控制；已公开内容的第三方副本无法保证收回。
