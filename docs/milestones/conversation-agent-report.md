# 预测对话 Agent 与行业入口

- 保存画像时，在同一事务里匹配或创建个人行业，并将当前画像行业排在「我的行业」首位。保留已有行业。选择「暂不按职业分类」时不创建行业。改造前保存的画像在下次保存时补齐。
- 公开行业沿用已有的一键复制入口，复制到当前账号的私人列表，使用自己的跟踪设置。
- 对话可以从个人行业、公开行业或自由提问开始。选行业作为讨论上下文时不自动关注。助手判断预测、决策、补问和添加意图。确认卡的写入受账号所有权、原始提议和同名检查保护。确认请求可安全重试。对话和提议在数据库中加密，新增行业默认私有。
- 本地引导支持明确的添加命令和范围补问。可选 DeepSeek 路径使用预测导向的系统提示与 JSON 输出。每条请求最多发送当前文本和前六条消息，以及适用的行业名称，不读取画像字段。每个账号 15 分钟最多 10 次请求且最多一个在途，单次超时 12 秒。
- 对话助手负责澄清目标、提出趋势假设和要核验的信号。联网检索、报告生成和定时监听各有独立的入口与规则。对话报告入口仍提供明确标记的演示报告。
- 迁移 `0021_conversation_agent` 允许对话没有行业，新增画像关联和模型额度表。两张表随账号删除，旧对话内容仍可读取。回退遇到新格式数据时会停下以保留原数据。

## 验收

- `make contracts` 生成 157 个领域 Schema 和 API 类型。
- 针对性回归通过，社区与收藏 11 项，新画像及对话 Agent 3 项。DeepSeek 测试使用模拟响应，覆盖开关、幂等请求和多轮上下文。
- `make build` 通过，Next.js 预渲染 16 个静态页面。
- `make check` 通过，Ruff、ESLint、TypeScript、mypy 101 个源文件，455 个 pytest 测试。测试环境报告 1 条 Starlette TestClient 弃用提示。
- `make local-verify` 通过，原生 PostgreSQL、Redis、API、Worker 与 Web 的冒烟测试通过，隔离数据库运行 455 个 pytest 测试和 22 条 Playwright 流程。浏览器实际验证了画像加入个人行业、聊天确认添加和刷新后恢复。
- `make up` 恢复本地服务，聊天页与 API 就绪接口均返回 HTTP 200。私有本机配置已启用可选 DeepSeek 对话，用户勾选后才会发送模型请求。本次验收未调用真实 DeepSeek。
