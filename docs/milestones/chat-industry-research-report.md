# Chat 行业研究任务

## 本轮范围

- 登录用户从任意私有会话选择可访问的行业和预测期限，确认运行 DEMO。新建会话可以先添加个人行业，再用该行业发起研究。
- API 在事务内保存范围快照、任务和请求事件。同账号同会话按请求标识幂等，提交期间最多一项研究，同一会话可保留多项已结束任务。
- Worker 复用行业研究编排，在进入检索、分析补证和写作时分别保存时间。浏览器按任务状态更新进度，重新打开会话可查看运行记录和私有草稿。
- 完成时由同一事务校验 Worker 租约、账号与行业访问权限，写入加密结果及完成事件。取消或删除对话会撤销在途任务的写入权。租约超期按现有 Worker 机制重新运行，同一个请求保持原范围。各阶段当前不单独续算。
- 研究产物附带条件预测、观察信号、证伪条件、行动和合成资料引用。结果放在原会话里。普通任务查询不返回私有草稿，账号导出可获取，删除会话或账号随之清除。
- 迁移 `0023_chat_research` 保存研究任务与会话关联、加密快照和阶段。已有首份报告流程和行业研究草稿是两个入口，各有独立数据格式。

## 验收

- 专项测试 7 项通过，覆盖 Worker 实际阶段、请求重放、冲突、跨账号与跨会话隔离、结果加密、取消和随会话清理。
- `make contracts` 生成 160 个领域 Schema 和 API 类型。
- `make build` 通过，Next.js 预渲染 16 个静态页面。
- `make check` 通过，Ruff、ESLint、TypeScript、mypy 106 个源文件，465 个 pytest 测试。
- 首次 `make local-verify` 的 465 项原生 PostgreSQL 测试与冒烟通过。浏览器初跑 21 项通过，1 项发现 Chat 登录状态初始化会覆盖输入草稿。修复了初始化顺序并保留已有输入，随后重跑 Web 构建和浏览器验收。
- 修复后 `npm run lint`、`npm run typecheck`、`make build` 通过。用 `PYTEST_ADDOPTS='-k test_worker_research_persists_private_progress_and_result' make local-verify` 重验，原生专项 1 项与完整 Playwright 22 项通过。浏览器验证了从新增行业到发起研究、刷新恢复和查看草稿。
- `make up` 恢复本地服务。聊天页和 API 就绪接口均返回 HTTP 200。研究演示使用确定性提供商。
