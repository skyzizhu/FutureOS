# M4 实施与验收报告

**M4 已实现，本机自动化验收通过；未进入 M5。**
部署继续使用本地 PostgreSQL、Redis、API、Worker 与 Web，无需 Docker。
本轮未新增付费模型/搜索调用、真实邮件发送或支付。

## 已交付

| 范围 | 当前行为 |
|---|---|
| 注册与会话 | 本地邮箱标识注册/密码登录/注销/过期；DB只保存密码 KDF 和会话 hash；Web使用 HttpOnly cookie，不向客户端 JSON 返回会话 token |
| 两级画像 | 产品自定义8个一级、24个二级行业；仅行业两级必填，岗位/地区/目标/任务/预算选填；父子关系服务端与数据库共同检查 |
| 画像隐私 | 选填使用授权默认关闭；生成最小、加密、不可变快照；撤回授权取消待生成报告；当前画像可编辑，不覆盖完成报告 |
| 个人影响 | 根据领域、条件机制、目标范围/地区和任务线索解释传播路径；低关联内容移至观察附录，不生成核心行动 |
| 决策与建议 | 区分 prepare/observe/no_action；预算、授权或证据不足时观察；高成本/不可逆/高风险动作不升为直接行动建议；保留成本/替代/验证/停止条件 |
| 私有报告 | Dashboard、报告正文与版本记录、固定世界预测版本、支持/反证、历史正反案例及差异、建议反馈、研究范围引导与本人导出 |
| 首次免费 | 按完整报告预留1份，成功消耗一次，失败/取消/耗尽释放；多条世界预测不重复扣；同用户并发只保留一次预留 |
| 版本复用 | 多位用户复用共享的已过审世界版本，各自独立报告/画像快照；REAL 无过审资料时失败释放，不回退或编造 |
| 邮件授权 | 预览摘要与鉴权链接；明确勾选并确认账号邮箱后保存一次本地模拟记录；不调用真实邮件服务，不自动外发 |

Core 继续只依赖 Pydantic/标准库。画像、邮箱、私有快照/报告、个人影响/建议与模拟收件人均加密保存；
行业代码、关联ID、状态与时间留在关系字段。私有内容不传给 DeepSeek，也不写入公共研究提示词或事件正文。

## 基础架构与约束

- `0007_m4`：新增19张账号、分类、画像、快照、权益/预留/ledger、报告/固定引用、影响/建议/反馈、本地模拟投递与共享合成目录表。
- `0008_m4_private_guards`：额外校验初始报告指针、预留 owner、完成报告后才能记消费、DEMO/REAL 引用一致及个人影响/建议归属。
- 13张快照/报告/关联/ledger等表 UPDATE/DELETE 被阻断；消费后的预留不能改回释放；私有报告只允许合法版本指针变动。
- 用户行锁使用 PostgreSQL FOR NO KEY UPDATE 串行化请求，同时避免阻塞完成事务的 FK key-share 校验。
- reserved/consumed 部分唯一索引、ledger 唯一约束、业务幂等键防止并发重复消费；报告成功与消费、Job、Outbox 同事务提交。
- 相同请求键重试复用原任务；刷新 Dashboard 可以找回本人的待处理任务，支持取消。
- 私有版本通过复合外键绑定报告/画像快照的 owner；API 再逐项检查 ownership。管理员没有读取他人私有报告的例外。
- 当前86个域 Schema，由 Pydantic 生成 JSON Schema/OpenAPI/TypeScript；Job 结果仅含报告ID，不带私有正文。

数据库实际核对：[M4-database.json](evidence/M4-database.json)。

## 用户入口

服务已启动，可直接打开 [注册/登录](http://127.0.0.1:3100/auth/login)，创建自己的本地账号。
随后选择一级和二级行业，进入 [我的报告](http://127.0.0.1:3100/dashboard)，保持 DEMO 生成首份完整报告。
不需要提供新 Key 或数据库配置。自动测试账号均为 example.invalid 合成标识，不供实际用户使用。

- DEMO 资料、世界版本和报告均显式标记；本轮成功生成的演示报告组合3个过审世界版本，仅消费一次。
- REAL 仅复用现有过审版本；目前真实覆盖很窄，不能承诺每个行业都有相关材料或完整新主题研究。
- 选填内容默认不使用；没有预算/任务/授权时只输出观察，不要求用户补填敏感信息才能完成报告。
- 邮件按钮仅保存本地模拟记录，未发送真实邮件。

## 私有密钥与限制

私有密钥默认 `.local/private-profile.key`，首次使用自动生成，权限0600。
**请与数据库分开备份该文件；丢失后，已有私有资料不能靠重设密码恢复。**
当前静态管理员身份仍只用于本地管理；普通用户使用独立注册会话。Web/API 均监听 loopback，不是公网部署方案。
具体恢复、配置与状态处理见 [本地手册](../runbooks/local.md)。

- 个性化为可解释规则/模板原型，不是通用因果发现、经过验证的个人收益模型或就业预测。
- 当前行业目录为产品自定义分类，非官方统计分类；页面主要为中文原型。
- 私有画像/报告不传外部模型；研究引导只确认范围，不冒充已完成任意新主题的研究。
- 邮箱验证、密码找回、账号删除、密钥轮换/KMS 和生产环境认证加固尚未实现。
- 撤回选填“使用”授权会取消待生成报告，但不自动删除已完成版本；当前选填可清空后保存，历史快照仍保留。
- 合成共享目录使用 native 单机文件锁；多主机部署和周期更新不在本轮范围。
- 尚无到期真实预测准确率或个人行动效果证据；M3 人工题组评审仍待进行。
- 没有实现 M5 周期研究/拐点/真实邮件，也没有 M6 商业支付。
