# 首页定位与画像 v2

2026-11-02。针对用户提出的六项修改实施，保持本地原生部署，不开启额外真实邮件、支付或联网模型调用。

- 首页标题为“预测行业未来，发现下一次机遇。”，显式定位“未来行业与机遇预测Agent”。说明AI实时监听、形成行业趋势/机遇预测报告的产品目标，同屏标出当前公开报告/演示体验与实时联网监听待接入的真实边界。
- 产品自定义行业目录由8个一级/24个二级扩为23个一级/259个二级；保留全部旧代码，新增每行业手填细分兜底。细分选择始终随父行业联动，换父级清空旧子级；自填细分随行业最小快照保留。
- 国家/地区提供258个CLDR名称选项，省/州手填；美国显示州、中国显示省/自治区/直辖市，换国家清空旧行政区。旧region文本保留，不猜测拆分；地区匹配优先新country_code，兼容旧region。
- 年龄、性别完全选填且可清空，现有加密JSON保存，无新增明文人口列。当前不进入研究快照、不用于预测和推荐排序，即使用户授权使用其他选填资料也会排除这两个值。
- 目标改成关注方向，可勾选或逐项补充；原任务改成工作/业务，逐项添加；可投入时间只用于限制行动建议，不影响报告速度。后两项放到可跳过的进阶区，附实际示例，保留旧协议与旧值，不要求分号输入。
- 岗位/地区/关注偏好仍需单独授权才进入研究快照，未授权只用行业；所有字段仅影响后续报告。国家目录读取失败可重试，已有画像读取失败时禁止覆盖保存。

数据来源、兼容策略、字段用途与回归竞态修正见ADR-022。新增迁移0016仅追加分类；当前研究预测规则不扩张。
