# 公开内容与个人行业体验

2026-11-02，本地原生 PostgreSQL / Redis，无 Docker；后台管理界面继续留待后续。

- 首页、行业、公开报告及发布流程统一使用“公开”的产品语义。
- 登录用户可把公开行业添加成自己拥有的私有副本，保留来源并可独立编辑；可管理多个行业及各自报告。添加幂等，不复制他人私人报告。
- 每个自有行业保存监听、预测和邮件提醒意愿，移除关注会暂停设置。页面明确等待抓取/提醒规则，尚未启用新的实时执行。
- 登录用户可下载公开报告 Markdown、点赞和收藏；真实计数、本人状态、作者站内消息和已读状态持久化。导航显示未读提示；重复取消再操作不会重复通知作者。
- 封装按钮、输入框、多行输入、复选框、开关及带键盘/滚动/边界避让的下拉控件；注册、画像、个人中心等现有流程使用统一控件。
- 外观支持跟随系统（默认）、浅色和深色；游客设备保存，登录用户账号数据库保存。首屏提前应用外观，短动画支持 reduced motion。
- 新业务数据纳入个人导出/删除，权限检查覆盖复制、行业设置、报告下载、点赞与消息已读。公开报告下载继续只包含公开快照，撤回后停止提供给其他读者。

设计和数据边界见 ADR-023。实时抓取/预测及邮件提醒规则由用户稍后提供，本次未添加自动外部搜索、付费模型或邮件任务。

## 验收记录

- `make contracts`：141 个领域 schema 与 API 类型生成成功。
- `make check`：Ruff、格式、ESLint、mypy 97 个源文件、Web TypeScript 与 427 pytest 通过；最终 UI 修正后另通过 ESLint 与 Next 生产构建。
- `make build`：最终 Next 生产构建成功。
- 最终 `make local-verify`：原生 PostgreSQL + Redis + API + Worker + Web，427 pytest（130.01 秒）、22 条浏览器流程（2.7 分钟）和持久队列 smoke 全部通过。唯一 Python 警告是已有 Starlette TestClient/httpx 弃用提示。
- 集成测试覆盖：同一来源添加幂等、独立编辑和两个行业设置、跨账号拒绝读取/修改、真实作者通知、重复动作去重、自互动无通知、本人已读、下载鉴权与撤回、外观隔离及导出/删除。
- 浏览器完整验证：注册与画像自定义选择控件、个人行业副本、报告下载文件、点赞/收藏与作者已读、账号深色主题重载、行业邮件意愿重载、系统模式响应 OS 外观变化、键盘选择与 390px 无页面横向溢出。既有注册、反机器人、管理员 MFA、账单、研究、隐私等流程同时回归。
- 初次新测试的点赞定位名称不一致，补齐可访问名称；随后测试暴露行业开关等待后端才变色，改为即时反馈、失败回退，并在测试中等待保存完成再重载。最终全量验收重跑通过。
- 实际浏览器检查浅/深色、窄屏导航和首屏定位，修正深色 Logo 对比度及中窄屏导航排列。主题/下拉仅使用 CSS 短过渡，未增加大型动画、视频或网络字体；沿用压缩 WebP 和懒加载报告缩略图。未进行公网或高并发性能验收。

验收使用独立 `_test` 库、本地预览验证码与虚构账号，SMTP、Turnstile 与 DeepSeek 外部调用在验收子进程禁用，正常 `.env` 配置保留。完成后恢复正常本地服务，数据库升级至 `0017_social`。

命令输出在 `evidence/social/` 的 `check.txt`、`lint-final.txt`、`contracts.txt`、`build.txt`、`native.txt`；实际浏览器深色首页为 `home-browser-dark.png`，桌面首页/报告和手机行业控件截图同目录。
