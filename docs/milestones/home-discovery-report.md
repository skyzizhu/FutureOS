# FutureOS 首页发现与独立公开报告

- 首屏以 Chat 为主入口，提供趋势、机会和个人决策的提问示例，也能直接进入对话。行业目录加载期间仍可开始对话。
- 公开行业和行业报告各占一个区块，桌面并排，手机顺序排列。行业 Banner 保留滑动和键盘切换，旁边的报告和 Chat 默认行业随选择更新。支持直接进入全部行业或对应行业详情。
- 独立公开报告单独展示。搜索覆盖所有可访问的公开报告，登录用户可切到按画像和关注行业排序的推荐结果。
- 报告发布支持选择公开行业或独立公开。后者不关联行业，只公开预览中的安全快照。独立报告支持原有阅读、互动、下载和撤回权限，收藏时可选个人行业。现有行业报告保留其公开行业归属。
- 迁移 `0024_standalone_reports` 允许公开快照没有所属行业。SQLite 已验证旧结构升级保留引用该报告的阅读计数及外键，原生 PostgreSQL 由本地验收覆盖。
- 视觉检查覆盖 1440px 浅色桌面、390px 深色手机和 320px 窄屏。首页提问输入在首屏，整页无水平溢出。

## 验收

- `make contracts` 重新生成 160 个领域 Schema 和 API 类型。
- 社区与社交专项测试通过 12 项，包含独立公开的权限、分区、下载与撤回。
- `make check` 通过，Ruff、ESLint、TypeScript、mypy 106 个源文件和 466 项 pytest。
- `make build` 通过，最终构建预渲染 16 个静态页面。
- 首次 `make local-verify` 的原生 466 项 PostgreSQL 回归与任务冒烟通过。首页、Chat 引导与行业切换浏览器流程通过。独立公开端到端测试捕获了导航提交前的旧 URL，等待原报告 URL 后复跑浏览器套件。
- 修正浏览器等待后，`PYTEST_ADDOPTS='-k test_standalone_publication_keeps_industry_private_and_can_be_withdrawn' make local-verify` 通过，包含原生专项和完整 22 条 Playwright 流程。访客可从独立区打开刚公开的报告。
- `make up` 已恢复本地服务，首页返回 HTTP 200。
